Code Kylar wrote by hand, running live.

These three programs come from Kylar’s CodeHS sandbox: a 4D tesseract renderer, a lexer/parser/interpreter for arithmetic, and a projectile basketball game. Each one runs here unchanged, next to its original source and CodeHS’s own edit history.

  • programs/Hand-written by Kylar on CodeHS, byte-for-byte as saved there. Each page shows a SHA-256 check.
  • site/This playground and the small CodeHS-compatible runtime were built with AI assistance.

The programs

  • 4D geometryJS Graphics

    funni cube

    A tesseract drawn as wireframe lines, spinning through three rotation planes at once.

    Idea: rotate a point in any pair of axes, including the fourth, then project 4D → 3D → 2D with two perspective divides.

    Run it →
  • CompilersJS Console

    overengineered-calculatoe

    Type an expression and it is tokenized, parsed into a tree and evaluated. Try 2^3^2.

    Idea: recursive descent, with one function per precedence level and a right-associative ^.

    Try it →
  • PhysicsJS Graphics

    bucketballs

    “Crappy Basketball”: set the angle and power, shoot, and hit a bobbing hoop before the 10-second clock runs out.

    Idea: step-by-step projectile physics with lossy bounces and hit-testing against the scene.

    Play it →
